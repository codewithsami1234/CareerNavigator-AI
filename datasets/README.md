# datasets/

Place datasets for later phases here (for example public resume or job-posting datasets).

**Rules**

- Never commit real people's resumes. Everything in this folder except this README is ignored by Git (see `.gitignore`).
- Record the source, licence and download date of every dataset in this file when you add one.
- Phase 1 and Phase 2 do not need a dataset in this folder. They ship with fully synthetic test resumes under
  `research/01_resume_intelligence/tests/fixtures/`. Phase 2 evaluation is fixture-based and is not a real-world OCR benchmark.
